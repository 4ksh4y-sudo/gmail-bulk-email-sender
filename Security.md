# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| Latest `main` | ✅ |
| Older tags | ❌ |

## Reporting a Vulnerability

**Please do not open a public issue for security problems.**

Email: `your-security-contact@example.com`

Include:
- Description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You'll get a response within 72 hours.

## Scope

In scope:
- Credential leakage
- Injection via recipient names or template
- TLS / certificate validation bypasses

Out of scope:
- Deliverability issues
- Google service outages
